# 配置知识的民主转置

### 从统御型配置知识到位置型配置知识

这是一个正在发展的研究项目，尝试从中国文化已有的配置知识中发展一种民主化路径。

项目的核心问题是：

> 能否把原本用于从中心观察、配置和调动他人的知识，转化为各个位置识别自身处境、相互依赖、调动力量和后果流向的共同能力？

---

## 一、研究对象

中国文化积累了丰富的政治、战略和历史推演知识，包括对“形”“势”“时”“位”“权”“变”“虚实”“奇正”和“大局”的理解。

这些知识能够帮助人们识别：

* 局势如何形成；
* 力量如何积累和转移；
* 不同位置如何相互影响；
* 行动时机如何出现；
* 局部变化如何改变整体；
* 秩序如何得到维持或发生转化。

本项目把这类用于理解和改变关系配置的知识统称为**配置知识**。

---

## 二、问题所在

配置知识包含观察位置、使用权限和后果结构。

其中相当一部分知识默认一个具有全局视野的中心观察者。知识使用者站在能够判断方向、安排位置、调动力量和解释后果的位置上，其他行动者则成为被观察、被配置或承担代价的位置。

当这类知识被公开和普及时，更多人可能学会从潜在统御者、战略家或整体代表者的位置思考。社会中的实际位置关系没有因此改变，中心化的观察方式却被复制到更多层级。

因此，配置能力的普及不会自动产生配置关系的民主化。

---

## 三、推演路径与意识形态

意识形态可以存在于反复使用的推演结构中。

“大势”“稳定”“顾全大局”“牺牲小我”“历史阶段”和“时机未到”等概念，能够组成逻辑连贯并且具有文化吸引力的判断路径。

当人们熟练使用这些路径时，可能把文化中已经存在的推演结构体验为自己的独立判断。

这使配置知识的民主转置需要发展一种第二阶识别能力：

* 我正在使用什么推演路径？
* 我从什么位置观察？
* 这个位置允许我看见什么？
* 哪些位置没有进入判断？
* 哪些代价被整体目标抽象化？
* 结论的后果被输送到哪里？
* 是否存在其他配置和行动通道？

---

## 四、统御型配置知识

统御型配置知识从中心位置观察局势，并用于：

* 识别和利用“势”；
* 塑造有利的“形”；
* 安排不同位置；
* 调动其他行动者；
* 判断整体方向；
* 选择行动时机；
* 维持秩序运行；
* 把局部代价纳入整体目标。

它的结构性风险来自观察权、配置权和后果分配权集中于同一位置。

---

## 五、位置型配置知识

位置型配置知识从多个有限位置出发，使每个位置能够识别：

* 自己处于怎样的关系中；
* 自己拥有和缺少哪些信息；
* 自己正在被什么力量调动；
* 自己依赖哪些其他位置；
* 自己的判断受哪些条件限制；
* 自己的行动被输送到哪里；
* 行动代价最终由谁承担；
* 谁取得了代表整体的权限；
* 当前配置如何被共同改变；
* 何时需要暂停、退出或重新判断。

它试图形成分布式的位置识别、共同判断和后果追踪能力。

---

## 六、初步转置方向

| 统御型用途         | 位置型转置                     |
| ------------- | ------------------------- |
| 识别如何利用“势”调动他人 | 识别自己如何进入某种“势”，以及正在被什么力量调动 |
| 塑造和安排他人的“形”   | 识别自身位置、限制、依赖和可改变条件        |
| 从中心判断行动时机     | 由不同位置共同识别行动阈值、暂停条件和退出条件   |
| 追求全局胜负        | 追踪局部代价、后果流向和不可逆损失         |
| 维持整体运行        | 检查整体由谁维护、依赖什么条件、把压力输送到哪里  |
| 代表整体作出决定      | 明确代表权的来源、范围、期限和撤回机制       |
| 将局部纳入统一目标     | 保留局部拒绝、退出和提出不同判断的能力       |
| 利用信息优势配置他人    | 让不同位置补充、质疑和修正局势描述         |

这些转换目前是研究假设，仍需通过传统文本分析、现代案例和方法实验继续检验。

---

## 七、民主意义

面对中国问题，西方式制度重构主要处理国家权力如何授权、制衡、监督和轮替。

配置知识的民主转置处理另一个层面：

> 社会如何持续生产能够代表整体、判断全局和配置其他位置的中心。

如果中国无法单纯依靠西方式制度转型完成民主化，民主能力可以从具体位置和配置关系中逐步形成：

* 识别自身位置；
* 识别调动力量；
* 追踪决定与后果；
* 审查整体代表权；
* 形成横向判断；
* 限定承担范围；
* 参与改变配置。

这些能力可以进一步探索适合中国社会的组织与制度形式。

关于两种路径的详细比较，见：

* [民主转型的两条路径](民主转型的两条路径.md)

---

## 八、当前研究任务

1. 确定配置知识的范围和基本类型；
2. 整理形、势、时、位、权、变等概念；
3. 识别不同知识所预设的观察位置；
4. 分析推演路径如何限定政治判断；
5. 区分知识传播与知识结构转置；
6. 建立从统御型用途到位置型用途的转换方法；
7. 通过具体案例检验位置识别和后果追踪；
8. 研究位置型配置知识能够生成哪些组织和制度。

---

## 九、开放问题

* 哪些配置知识天然依赖中心位置？
* 哪些知识可以转置，哪些需要重新构造？
* 多个位置如何形成共同判断？
* 如何防止共同判断产生新的隐形中心？
* 位置识别如何转化为实际行动能力？
* 如何处理位置之间的信息、资源和风险差异？
* 临时中心如何形成、受到限制并最终退出？
* 配置知识的民主转置如何接受持续审查？

---

## 十、项目状态

本项目目前处于概念形成、材料整理和方法探索阶段。

当前形成的主要概念包括：

* 配置知识；
* 统御型配置知识；
* 位置型配置知识；
* 配置知识的民主转置；
* 推演路径的第二阶识别。

仓库将用于保存概念定义、基础论证、材料分析、转置方法和案例研究。
