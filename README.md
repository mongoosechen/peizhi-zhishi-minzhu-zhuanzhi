# 配置知识的民主转置

### 从统御型配置知识到位置型配置知识

这是一个正在发展的研究项目，尝试通过配置知识的转置推进中国文化内部的民主化，并观察这种文化变化能够生成怎样的社会运作结构。

项目的核心问题是：

> 能否把原本用于从中心观察、配置和调动他人的思考方法，转化为各个位置都能识别、检验并改变思考方法本身的文化能力？

## 研究对象

中国文化积累了丰富的政治、战略和历史推演知识，包括对“形”“势”“时”“位”“权”“变”“虚实”“奇正”和“大局”的理解。

这些知识能够帮助人们识别局势如何形成、力量如何积累和转移、不同位置如何相互影响、行动时机如何出现，以及局部变化如何改变整体。本项目把这类用于理解和改变关系配置的知识统称为**配置知识**。

## 问题所在

配置知识包含观察位置、使用权限和后果结构。

其中相当一部分知识默认一个具有全局视野的中心观察者。知识使用者站在能够判断方向、安排位置、调动力量和解释后果的位置上，其他行动者则成为被观察、被配置或承担代价的位置。

当这类知识被公开和普及时，更多人可能学会从潜在统御者、战略家或整体代表者的位置思考。社会中的实际位置关系没有因此改变，中心化的观察方式却被复制到更多层级。

因此，配置能力的普及不会自动产生配置关系的民主化。

## 推演路径与意识形态

意识形态可以存在于反复使用的推演结构中。

“大势”“稳定”“顾全大局”“牺牲小我”“历史阶段”和“时机未到”等概念，能够组成逻辑连贯并且具有文化吸引力的判断路径。人们熟练使用这些路径时，可能把文化中已经存在的推演结构体验为自己的独立判断。

配置知识的民主转置需要发展一种第二阶能力，使思考方法本身成为可以被观察和改变的对象：

- 我正在使用什么推演路径？
- 我从什么位置观察？
- 这个位置允许我看见什么？
- 哪些位置没有进入判断？
- 哪些代价被整体目标抽象化？
- 结论的后果被输送到哪里？
- 是否存在其他配置和行动通道？
- 这个推演方法能否从其他位置重新组织？
- 谁能够参与改变共同使用的思考方法？

## 统御型配置知识

统御型配置知识从中心位置观察局势，并用于：

- 识别和利用“势”；
- 塑造有利的“形”；
- 安排不同位置；
- 调动其他行动者；
- 判断整体方向；
- 选择行动时机；
- 维持秩序运行；
- 把局部代价纳入整体目标。

它的结构性风险来自观察权、配置权和后果分配权集中于同一位置。

## 位置型配置知识

位置型配置知识从多个有限位置出发，使每个位置能够识别：

- 自己处于怎样的关系中；
- 自己拥有和缺少哪些信息；
- 自己正在被什么力量调动；
- 自己依赖哪些其他位置；
- 自己的判断受哪些条件限制；
- 自己的行动被输送到哪里；
- 行动代价最终由谁承担；
- 谁取得了代表整体的权限；
- 当前配置如何被共同改变；
- 何时需要暂停、退出或重新判断。

它使不同位置能够参与改变共同使用的推演方法。判断方式因此不再以固定形式从中心向外扩散，而能够随着位置、关系和后果发生变化。

## 初步转置方向

| 统御型用途 | 位置型转置 |
|---|---|
| 识别如何利用“势”调动他人 | 识别自己如何进入某种“势”，以及正在被什么力量调动 |
| 塑造和安排他人的“形” | 识别自身位置、限制、依赖和可改变条件 |
| 从中心判断行动时机 | 由不同位置共同识别行动阈值、暂停条件和退出条件 |
| 追求全局胜负 | 追踪局部代价、后果流向和不可逆损失 |
| 维持整体运行 | 检查整体由谁维护、依赖什么条件、把压力输送到哪里 |
| 代表整体作出决定 | 明确代表权的来源、范围、期限和撤回机制 |
| 将局部纳入统一目标 | 保留局部拒绝、退出和提出不同判断的能力 |
| 利用信息优势配置他人 | 让不同位置补充、质疑和修正局势描述 |

这些转换目前是研究假设，仍需通过传统文本分析、现代案例和方法实验继续检验。

## 研究意义与边界

本项目当前是一项知识发展工作。它研究中国文化中的配置知识，识别这些知识如何安排观察位置和推演方向，并尝试发展转置它们的方法。

文化民主化是这项知识工作的方向性假设。它意味着：

- 共同使用的推演路径可以被不同位置辨认；
- 思考方法的观察点、适用范围和后果可以被质疑；
- 原本用于配置他人的知识可以从被配置的位置重新理解；
- 各个位置能够参与改变判断方式本身；
- 没有任何位置永久垄断解释整体和修改共同思考方法的权限；
- 一种思考方法造成的盲点和代价能够反过来改变这种方法。

因此，转置的目标不只是给出一套新的思考方法。它要探索如何把**思考方法的转变能力**分布到文化内部。

西方民主经验可以帮助说明：正式制度能够分配和限制政治权力，却不会自动改变文化中生产整体判断、战略中心和他人配置的方式。如果这些思考方式持续存在，它们可能进入不同制度并重新集中权力。

这项研究目前尚未发展到制度设计，也不提出中国应采用的转型程序。配置知识发生转置以后是否会形成新的社会运作结构、形成什么结构，均属于后续问题。

详细说明见：[为什么从配置知识开始](为什么从配置知识开始.md)。

## 当前研究任务

1. 确定配置知识的范围和基本类型；
2. 整理形、势、时、位、权、变等概念；
3. 识别不同知识所预设的观察位置；
4. 分析推演路径如何限定政治判断；
5. 区分知识传播与知识结构转置；
6. 建立使思考方法本身可被转置的操作；
7. 通过材料和案例检验不同位置能否修改共同推演路径；
8. 建立判断一次转置是否真正改变知识结构的标准。

## 开放问题

- 哪些配置知识天然依赖中心位置？
- 哪些知识可以转置，哪些需要重新构造？
- 多个位置如何共同改变判断方法？
- 如何防止新的思考方法形成隐形中心？
- 一种推演方法产生的后果如何反过来修改这种方法？
- 如何处理位置之间的信息、资源和风险差异？
- 如何判断知识转置已经发生，而不是换了一套语言继续使用原有逻辑？
- 配置知识的民主转置如何接受持续审查？

## 项目状态

本项目目前处于概念形成、材料整理和方法探索阶段。当前形成的主要概念包括：

- 配置知识；
- 统御型配置知识；
- 位置型配置知识；
- 配置知识的民主转置；
- 推演路径的第二阶识别。
