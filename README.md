# 配置知识的民主转置

### 从统御型配置知识到位置型配置知识

这是一个正在发展的研究项目，尝试从中国文化已有的配置知识中发展一种民主化路径。

项目的核心问题是：

> 能否把原本用于从中心观察、配置和调动他人的知识，转化为各个位置识别自身处境、相互依赖、调动力量和后果流向的共同能力？

---

## 一、研究缘起

中国文化积累了丰富的政治、战略和历史推演知识，包括对“形”“势”“时”“位”“权”“变”和“大局”的理解。

这些知识能够识别局势如何形成、力量如何积累、位置如何相互作用，以及局部变化如何影响整体。其中相当一部分知识默认一个具有全局视野的中心观察者：由它判断方向、配置关系、选择时机和调动其他位置。

当这类知识被广泛传播，中心化的观察方式也可能随之扩散。更多人开始从潜在统御者、战略家或整体代表者的位置思考，各个实际位置所需要的自我识别、横向协调和后果追踪能力仍然不足。

本项目将前一种知识暂称为**统御型配置知识**，并尝试将其转化为**位置型配置知识**。

---

## 二、为什么需要另一条民主化路径

面对中国问题，西方式制度转型主要关注：

* 国家权力如何获得授权；
* 执政者如何被选出和替换；
* 权力如何受到法律、司法、媒体和社会组织的制约；
* 公民的基本权利如何获得保障。

这些制度能力具有不可替代的价值。

本项目进一步提出：如果中国无法单纯依靠西方式制度转型，民主还需要从社会内部的知识结构和配置关系中生长。

因为权力集中也存在于人们理解局势、整体和自身位置的方式中：

* 谁可以代表整体；
* 谁能够定义“大局”；
* 谁负责判断历史方向；
* 谁被要求承担牺牲；
* 局部代价如何被纳入整体目标；
* 反对旧中心的人是否正在建立新的中心。

配置知识的民主转置尝试改变民主转型的起点和生成顺序：

> 从局部位置与配置关系开始，形成位置识别、横向判断、后果追踪和整体代表限制能力，再从这些能力中探索相应的组织与制度形式。

## 三、核心概念

### 统御型配置知识

从中心位置观察局势，并用于：

* 识别和利用“势”；
* 塑造有利的“形”；
* 安排不同位置；
* 调动其他行动者；
* 判断整体方向；
* 选择行动时机；
* 维持秩序运行；
* 把局部代价纳入整体目标。

它的结构性风险，是观察权、配置权和后果分配权集中在同一位置。

### 位置型配置知识

从多个有限位置出发，使每个位置能够识别：

* 自己处于怎样的关系之中；
* 自己正在被什么力量调动；
* 自己依赖哪些其他位置；
* 自己的判断受哪些条件限制；
* 自己的行动被输送到哪里；
* 行动代价最终由谁承担；
* 谁取得了代表整体的权限；
* 当前配置如何被共同改变；
* 何时需要暂停、退出或重新判断。

### 整体承担位置

“整体”需要通过具体的人、组织和知识系统获得行动能力。

当一个有限位置取得替整体判断方向、分配任务和承担历史后果的权限时，它就成为一个**整体承担位置**。

本项目研究这种位置如何形成、如何取得正当性、如何调用其他位置，以及如何被限制、分解、暂停和撤回。

### 局部解除动员

整个社会同时退出历史动员并不现实。解除动员可以在具体位置、事件和有限时间中逐步发生：

* 允许个体和群体暂时不再代表整体；
* 使失败无需立即转化为胜负解释；
* 让行动者获得暂停、退出和重新判断的条件；
* 让具体后果在下一轮行动开始前得到处理。

它意味着社会逐步形成停止持续调用人的能力。

### 损失的非征用化处理

损失经常被转化为牺牲、教训、使命、胜利证明或下一轮动员的资源。

损失的非征用化处理使死亡、失败、创伤和被消耗的生活保持其具体性与不可替代性，并获得独立的确认、记录和处理。

## 四、初步转置方向

| 统御型用途         | 位置型转置                     |
| ------------- | ------------------------- |
| 识别如何利用“势”调动他人 | 识别自己如何进入某种“势”，以及正在被什么力量调动 |
| 塑造和安排他人的“形”   | 识别自身的位置、限制、依赖和可改变条件       |
| 从中心判断行动时机     | 由不同位置共同识别行动阈值、暂停条件和退出条件   |
| 追求全局胜负        | 追踪局部代价、后果流向和不可逆损失         |
| 维持整体稳定        | 检查稳定由谁维护、依赖什么条件、把压力输送到哪里  |
| 代表整体作出决定      | 明确代表权的来源、范围、期限和撤回机制       |
| 将局部纳入整体目标     | 保留局部拒绝、退出和提出不同后果判断的能力     |
| 用牺牲证明历史方向     | 使损失脱离使命化解释并获得独立处理         |

这些转置目前是研究假设，需要通过文本分析、案例研究和方法实验继续发展。

---

## 五、项目的研究方向

### 1. 配置知识整理

整理中国传统思想和日常语言中的配置知识，包括：

* 《孙子兵法》中的形、势、虚实、奇正与时机；
* 《道德经》中的位置、反转、无为、柔弱与关系变化；
* 《三十六计》中的配置操作、通道和杠杆；
* 成语、俗语和历史叙事中的大局判断与推演结构。

### 2. 知识结构分析

识别每种配置知识所预设的：

* 观察位置；
* 使用权限；
* 配置对象；
* 判断范围；
* 代价承担者；
* 退出与修正条件。

### 3. 民主转置方法

研究配置知识如何改变观察方向、权限结构和后果关系，并逐步形成可以实际使用的转置方法。

### 4. 案例研究

在官僚组织、社会动员、技术治理、艺术实践、地方记忆和小型共同体中检验相关概念。

### 5. 组织与制度生成

研究位置型配置知识能够支持哪些组织程序、授权方式、暂停机制、退出条件和制度保护。

## 八、开放问题

* 哪些配置知识天然依赖中心位置？
* 哪些知识可以直接转置，哪些需要重新构造？
* 多个位置如何形成共同判断，同时避免产生新的隐形中心？
* 位置识别如何转化为实际行动能力？
* 局部解除动员如何避免成为逃避责任的工具？
* 损失如何获得非征用化处理，同时保留公共意义？
* 位置型配置知识能够生成怎样的组织和制度？
* 民主转置本身如何接受持续审查和修正？
